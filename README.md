# alu-system_engineering-devops

System engineering and DevOps projects for the ALU curriculum.

## Projects

- [ssh](./ssh) - Connecting to a server with SSH keys and configuring the SSH client
- [load_balancer](./load_balancer) - Configuring two web servers behind an HAProxy load balancer
- [firewall](./firewall) - Blocking all incoming traffic on a server except SSH, HTTP and HTTPS with ufw
